# Saves a layout under a name, loads it back, resets to the default layout,
# then ends as a crash would, a few seconds after a last change. The follow up
# script starts the app again in the same profile to see what it kept.
# View menu rows at 1600x900: Statistics 70, Layouts 426. With one layout
# saved, the Layouts submenu has it at 426, Save current layout at 456, and
# Reset to default layout at 510.

#! then layouts-kept
size 1600 900
wait 20
open $MEDIA
wait 120
